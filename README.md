TOTEM DE AUTOATENDIMENTO - HOSPITAL SABARÁ

Este projeto foi desenvolvido em Python com o framework Kivy como parte da disciplina de desenvolvimento de aplicações.

OBJETIVO
Automatizar a triagem de pacientes por meio de um totem interativo, permitindo que o próprio paciente insira seus dados e realize uma autoavaliação de sintomas. O sistema então realiza uma classificação automática por prioridade de atendimento.

FUNCIONALIDADES
- Interface gráfica com campos para:
  • Nome completo
  • Data de nascimento (formatação automática)
  • RG
  • Telefone de contato
- Autoavaliação de sintomas:
  • Dor (com intensidade de 1 a 10)
  • Febre (temperatura corporal)
  • Náusea
  • Vômito
- Classificação automática de urgência:
  • Muito Emergente
  • Urgente
  • Emergente
  • Estável
- Organização automática da fila de atendimento com base na gravidade.

REQUISITOS PARA EXECUÇÃO
É necessário ter o Python 3 instalado, além da biblioteca Kivy.

INSTALAÇÃO DAS DEPENDÊNCIAS
Abra o terminal e execute:
pip install kivy

Recomenda-se o uso de um ambiente virtual (venv) para isolar os pacotes.

COMO EXECUTAR
No terminal ou prompt de comando, digite:
python main.py

TECNOLOGIAS UTILIZADAS
- Python 3.x
- Kivy
